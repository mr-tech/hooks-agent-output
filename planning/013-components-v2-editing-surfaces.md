## Objective

Restore one invariant across `website`'s message-data surfaces, stated by the architect during the research and adopted here as the thing every milestone is measured against:

- **Projection confinement**: the output of a display projection never crosses a write boundary, never seeds a control whose value can be committed, and never feeds change detection.
- **Round-trip closure**: for every stored `data` value *d* the server accepts, `stripKeys(makeEditable({data: d})).data ≡ d` modulo `_key`s and key order.
- **The V2 flag never stands over classic content**: on every save `stripKeys` sets the bit whenever V2 components are present (structure → flag, one direction); a bit standing over content or embeds is the conflict the rider refuses (D5, class per D13); a bit standing over non-V2 components or over none is **not** a conflict — it is tolerated as a marking, Discord's on ingress (D12) or the user's on a JSON surface (D13), and `stripKeys` never clears it. The clause is stated as flag/classic-content exclusivity rather than as "flags derive from structure" because the owner ruled the components check out of the conflict (D13); the architect's invariant from the research is thereby qualified at the one point the owner chose, and the qualification is named here rather than left implicit.

### M2 — The JSON modal is a round-trip editor, and the rider clause

**Objective**: opening Message JSON and pressing Load without editing changes nothing; what a user edits is what is committed; a typed V2 `flags` bit standing over content or embeds is refused, naming the conflict (D5, class per D13).

**Acceptance criteria (properties)**:
