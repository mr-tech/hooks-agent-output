## Lessons Learned

1. **A generated artefact pinned by bytes inherits every gate the repository runs.** The cheapest moment to make it conform is when it is generated, before its digest becomes a criterion. Once the digest is in the plan, every gate it fails is a plan revision.
2. **Declining a mechanically verifiable regeneration "to avoid re-opening a criterion" buys about an hour.** Here the regeneration's data identity was checkable in one command (`compare_fixture.mjs`, 120 of 120). The criterion re-opened anyway, at a costlier gate.
3. **A test table generated from faults × placements still tests one position unless position is an axis.** "Every item" in a criterion is a third axis. A mutant set without a walk-truncation operator cannot see the gap.
4. **An instrument that emits artefacts, uncategorised, makes two honest stages disagree.** The JSX-bracket rows got two different dispositions from the same table.
5. **A gate is only as good as the freshness of its reading.** Acting on an uncaptured `source` field produced a wind-down nobody needed.
