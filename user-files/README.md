# user-files/

Raw operator-supplied captures — logs, console output, screenshots' accompanying text — kept
**verbatim** as evidence.

**Written by the operator, not by agents.** The point of this directory is that its contents are not
paraphrased, trimmed or reformatted by anything: a document elsewhere in this repository may quote
and interpret a capture, but the capture itself stays exactly as it arrived. Where an agent's reading
of a capture matters, that reading goes in the agent's own document, in a section marked as the
agent's, never edited into the file here.

*Empty.*
